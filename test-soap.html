🧪 Test Service SOAP - Gestion des Serveurs

📌 URL du service : http://localhost:8081/ws
📌 Port : 8081
⚠️ Assurez-vous que votre application Spring Boot est démarrée !

1. Créer un serveur (CreateServerRequest)

2. Lister tous les serveurs (GetAllServersRequest)

3. Démarrer un serveur (StartServerRequest)

4. Arrêter un serveur (StopServerRequest)

5. Renommer un serveur (RenameServerRequest)

6. Supprimer un serveur (DeleteServerRequest)
